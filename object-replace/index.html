Selected-area recoloring · Browser-based workflow

Object Replace

Blends a chosen color into the selected region while retaining some original shading.

Open Object Replace

No account required. Keep your original and review the result before sharing.

How to use this tool

Select the object with the brush or lasso, choose a color and start with a moderate intensity.

A practical example

Recolor a fabric panel without changing the surrounding room, then inspect the selection boundary.

What to expect

This changes color; it does not replace the object with a different generated object.

Input and export

The main workspace accepts JPG, PNG, WebP, BMP and GIF images, plus HEIC through a downloadable decoder. GIF animation is not retained. Inputs are limited to 25 MB and 40 megapixels; some devices need smaller images. Exports use the actual browser-supported format shown on the download link. OCR exports plain text and the collage accepts additional JPG, PNG and WebP files.

Check the result

Compare the original and edited previews at the size you intend to use. Use Undo if an adjustment removes detail. File dimensions, transparency and format matter as much as the preview. Download before closing the tab: the editing session is not a saved project.

Privacy and dependencies

Image processing runs in your browser in this release. Recognition models and libraries may download from third-party hosts, which receive ordinary network requests. Selected images are not sent to a paid AI service. Read the privacy policy for preferences, advertising and network details.
