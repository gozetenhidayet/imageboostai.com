Object Replace

Object Replace recolors a region you select. The tool blends your chosen color into the selected pixels while keeping part of the original brightness and shading, so folds, highlights and shadows remain visible. You select the region with the same Brush (size 8 to 90) or Lasso used by Object Remover, pick a color, and set Intensity from 10% to 100%; it starts at 55%.

Open Object Replace

No account required. Keep your original and review the result before sharing.

Despite the name, it does not swap an object for a different one. Replacing a lamp with a plant would require a generative image model, which this site does not use. Treat the tool as a precise color changer for clothing, furniture, walls and similar flat-colored objects.

When to use Object Replace

  • You want to see a shirt, a car or a piece of furniture in another color.
  • You need to tone down a distracting bright object in the background.
  • You are mocking up color variants of a product for a quick comparison.

Step by step

  1. Upload the photo and open Object Replace.
  2. Select the object with the brush or lasso. Follow the edge carefully and avoid neighboring objects.
  3. Pick a new color and start with the default intensity.
  4. Press Apply Color and review the selection boundary for color spill onto nearby areas.
  5. Increase intensity for a stronger color or undo and reduce it to keep more of the original tone, then download.

Tips for better results

  • A lasso gives cleaner edges on straight objects; a small brush works better on irregular shapes.
  • Dark source colors accept light replacement colors poorly because the original shading is retained. Try a higher intensity or a mid-tone color.
  • Zoom to 100% to check the edge. A thin line of the old color is the most common flaw.
  • Keep the result realistic by choosing colors that exist in real materials.

Common mistakes

  • Expecting the object to be replaced by a different object.
  • Selecting skin or hair along with clothing, which causes unnatural color shifts.
  • Using maximum intensity on highlights. They can turn into flat patches of color.

What to expect

This changes color; it does not replace the object with a different generated object.

Input, export and privacy

The workspace accepts JPG, PNG, WebP, BMP, GIF and HEIC images up to 25 MB and 40 megapixels; some devices need smaller files. Your image is processed in your browser and is not sent to our servers. Models and libraries, where a tool needs them, download from public content networks. See the privacy policy for the full list.

Questions about Object Replace

Can it turn a red dress blue?

Yes, in most cases. Select the dress and choose a blue; the shading of the fabric is kept. Very saturated or very dark source colors may need a higher intensity.

Why is the tool called Object Replace if it only recolors?

The name is from an earlier version of the site. We describe the actual behavior in the interface and in this guide so that nobody has to guess.

Will it recolor only the selected area?

Yes. Pixels outside the selection are left unchanged, although the soft edge of your mask can tint a few neighboring pixels.
