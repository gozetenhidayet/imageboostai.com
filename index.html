A reliable photo workflow

Start with the clearest original you have. Crop and resize before making color adjustments, then compare the result against the original. Download a copy before closing the tab.

Choose the right export

PNG keeps transparency and hard text edges. JPEG suits photographs but discards transparency and introduces compression. WebP supports both photographic compression and transparency. Compare the displayed file size and actual preview instead of expecting a fixed percentage saving.

Know the limits

Most tools use local pixel operations. OCR downloads Tesseract language data; background isolation downloads a segmentation model and discloses its edge-color fallback. Legacy “AI” tool names do not imply generative reconstruction. Colorization is a tint, upscaling interpolates pixels, and repair cannot recover hidden detail.

Work with large files

The editor accepts up to 25 MB and 40 megapixels, with a maximum of 16,384 pixels per side. Mobile memory may impose a lower practical limit. Animated images use the first frame. HEIC needs an external decoder and is not supported for every variant.
