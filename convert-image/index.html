PNG, JPEG and WebP export · Browser-based workflow

Convert Image

Convert Image exports your current picture as PNG, JPG or WebP. Click a format button and the file is encoded immediately. PNG is lossless and keeps transparency, JPG is smaller for photographs but has no transparency, and WebP is a modern format that is usually smaller than both, where the browser supports it.

Open Convert Image

No account required. Keep your original and review the result before sharing.

For JPG output, a color picker (default white) sets the background that appears behind transparent areas. HEIC photos from iPhones can be opened as input: the tool loads a decoder from the cdnjs CDN and converts the photo to a standard image first. HEIC is not available as an output format. The download link always shows the format that was actually produced, so if a browser cannot encode WebP and falls back to another type, the file extension follows the real format.

When to use Convert Image

  • A website asks for JPG or PNG and your photo is in HEIC or WebP.
  • You need a transparent PNG from a cutout you made with Remove Background.
  • You want a WebP version of an image to speed up a web page.

Step by step

  1. Upload the file. HEIC, JPG, PNG, WebP, GIF and BMP are accepted.
  2. Open Convert Image. If you plan to export JPG, pick a background color for transparent areas.
  3. Click PNG, JPG or WEBP.
  4. Check the download button, which shows the format and size of the result.
  5. Download the file.

Tips for better results

  • Use PNG for graphics, screenshots and cutouts, JPG for photographs, and WebP when a smaller file is more important than universal compatibility.
  • A GIF is converted using its first frame only, so animation is not kept.
  • Converting to a lossy format such as JPG or WebP and back to PNG does not restore lost detail.
  • If you also need a smaller file, convert first, then use Image Compressor.

Common mistakes

  • Converting a transparent image to JPG and being surprised by the background. Choose a background color before converting, or use PNG or WebP.
  • Expecting HEIC as an output format. It is supported only as an input.
  • Re-saving a JPG as JPG repeatedly, which degrades quality each time.

What to expect

HEIC output is not supported. Browser support can cause WebP encoding to fall back; the download extension follows the actual encoded type.

Choose PNG for a transparent cutout, JPEG for an opaque photo or WebP for supported web delivery.

Input, export and privacy

The workspace accepts JPG, PNG, WebP, BMP, GIF and HEIC images up to 25 MB and 40 megapixels; some devices need smaller files. Your image is processed in your browser and is not sent to our servers. Models and libraries, where a tool needs them, download from public content networks. See the privacy policy for the full list.

Questions about Convert Image

Can I convert to HEIC?

No. HEIC is supported only as an input, because browsers cannot encode it.

Why is the file extension different from the button I clicked?

If a browser cannot produce the requested format, for example WebP in an older browser, the tool downloads the format that was actually created and names the file accordingly.

Is the quality the same after conversion?

PNG is lossless. JPG and WebP are lossy, so a small amount of detail is lost. At normal quality the difference is rarely visible.
